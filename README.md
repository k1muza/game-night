# Game Night

Mobile-first party games for Zimbabwean youth aged 16–30, with African and global appeal. Original content, family-friendly tone, one phone per team by default.

## Content library

| Game | Cards | Dataset |
|---|---:|---|
| 30-Second Sprint | 400 | [cards](content/thirty-seconds/cards.jsonl) |
| Charades | 600 | [cards](content/charades/cards.jsonl) |
| Trivia Challenge | 800 | [cards](content/trivia/cards.jsonl) |
| Forbidden Words (Taboo-inspired) | 500 | [cards](content/forbidden-words/cards.jsonl) |
| **Total** | **2,300** | |

All four candidate libraries are present. Counts do not imply editorial approval, verified facts or production readiness. See [content documentation](content/README.md) for layout, provenance, schema compatibility and release gates.

Foundational design: [research.md](research.md).
