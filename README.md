# Game Night

Mobile-first party games for Zimbabwean youth aged 16–30, with African and global appeal. Original content, family-friendly tone, one phone per team by default.

## Content targets

| Game | Launch library |
|---|---:|
| 30-Second Sprint | 400 cards (2,000 terms) |
| Charades | 600 prompts |
| Trivia Challenge | 800 questions |
| Forbidden Words | 500 cards |

The research report is a design reference, not the source of production cards. New cards are authored in batches and kept in `content/drafts/` until editorial review, source verification (trivia), and playtesting are complete. No commercial card sets are copied.

See `content/README.md` for the content contract and release gates when available. Application implementation is out of scope for the initial content commits.
