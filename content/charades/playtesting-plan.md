# Human playtesting plan

Recruit 6–10 groups of 6–10 participants, stratified across ages 16–21 / 22–30, urban / peri-urban / rural, language and interests. Obtain consent; use appropriate guardian consent where required for minors; collect anonymous player codes rather than names. Use 60-second turns, Correct/Pass and the agreed silent house rules. Rotate actors, randomise deck order and balance difficulty/categories. First run 120-card stratified pilot; then cover all 600 with a balanced incomplete-block design and aim for at least five independent exposures per card. Record each attempt independently.

Fields: cardId, group/actor code, age band, language, location stratum, prior familiarity (actor privately before mime, guessers after reveal), correct/pass, seconds elapsed, guessed answer, actor confidence 1–5, enjoyment 1–5, category usefulness 1–5, dispute flag, observed failure reason (actor unknown; guessers unknown; communication failure; different entity; ambiguous wording). Use anonymous feedback. Never reveal hint metadata during play.

Provisional gates: actor familiarity ≥80%; team familiarity ≥70%; easy solve ≥75%, medium 50–75%, hard 30–55%; median successful solve ≤25 seconds overall; disputes <5%; no unsafe performances; no subgroup gap >20 percentage points without explanation. These are pilot hypotheses, not validated standards. Check uncertainty for small samples. Rewrite/reclassify weak cards, retest revised ones, require independent Zimbabwean and Ndebele/Shona language reviewers, verify titles and named references, review semantic overlap, and run Dart adapter + Flutter tests. No results claimed.
